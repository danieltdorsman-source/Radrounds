# RadRounds

**Practical radiology for the ward.**

RadRounds is an educational radiology website for medical students and junior doctors. It combines real open CT reference stacks, anatomy review, high-yield pathology patterns, an acute stroke workflow and ward-focused imaging request tools.

## Live site

GitHub Pages deployment is configured through `.github/workflows/pages.yml`.

## Important

RadRounds is for education and workflow support only. It is not a diagnostic viewer, medical device, substitute for a formal radiology report, or replacement for current local protocols and senior/specialist advice.

## Imaging sources

The site credits open/reference imaging within the Guidelines section. Real CT assets remain hosted by their source repositories and are loaded at runtime.
